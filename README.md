# 💧 물 한 잔

오늘 마신 물의 양을 컵 단위로 기록하는 아주 가벼운 PWA(Progressive Web App)입니다.
설치 없이 브라우저에서 바로 쓸 수 있고, 홈 화면에 추가하면 앱처럼 실행됩니다.

## 주요 기능

- **4x2 컵 그리드**: 컵을 탭할 때마다 하나씩 채워지며 오늘 마신 물의 잔 수를 기록
- **목표 달성 축하 애니메이션**: 8잔을 모두 채우면 컨페티(색종이) 애니메이션으로 축하
- **자동 저장**: `localStorage`를 이용해 날짜별로 기록을 저장, 새로고침해도 유지
- **오늘 기록 지우기**: 버튼 한 번으로 당일 기록 초기화
- **오프라인 지원**: 서비스 워커(`sw.js`)로 오프라인에서도 앱 실행 가능
- **홈 화면 설치**: `manifest.json` 기반 PWA로 iOS/Android에서 홈 화면에 추가 가능

## 사용 방법

1. `index.html`을 브라우저로 열거나, 정적 파일을 웹 서버에 배포합니다.
2. 물을 마실 때마다 컵을 탭하세요.
3. 하루가 지나면 자동으로 새 날짜 기록으로 초기화됩니다.
4. 오늘 기록을 다시 지우고 싶다면 "오늘 기록 지우기" 버튼을 누르세요.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱의 UI와 로직(컵 그리드, 저장/축하 애니메이션 등) |
| `manifest.json` | PWA 매니페스트 (앱 이름, 아이콘, 테마 색상 등) |
| `sw.js` | 오프라인 사용을 위한 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 기술 스택

- 순수 HTML / CSS / JavaScript (별도 프레임워크·빌드 과정 없음)
- Web App Manifest, Service Worker (PWA)
